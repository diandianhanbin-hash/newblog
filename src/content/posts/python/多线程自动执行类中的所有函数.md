## 背景
电脑每次开机总有许多服务要起，比如MongoDB、爬虫、本地网站的服务等等，这些都分布在各个文件夹，每次重启电脑都需要到各个目录下去启动服务，虽然也不会花多少时间，但是非常麻烦，所以就看了一下多进程来解决这个问题。

## 思路
每一个服务都是独立的，切启动之后不会关闭，那么传统的直线型写代码肯定不行，必须要多个进程来处理这些东西。

## 开始
多线程的内容我就不多写了，最初我是按照网上的demo来写的，非常简单粗暴：

```python
import os
import multiprocessing

def pabing():
    os.system("python /Users/SvenWeng/Develop/H5/pachong/pabing/run.py")

def mongod():
    os.system("mongod")

if __name__ == '__main__':
    threads = []
    t1 = multiprocessing.Process(target=pabing)
    threads.append(t1)
    t2 = multiprocessing.Process(target=mongod)
    threads.append(t2)
    for t in threads:
        t.start()  
```
这种写法非常简单，就是手工直接开进程，需要几个进程就手工开几个，但是如果服务多了，这样写起来就会很累，有没有更好的办法呢？

## 使用进程池
上面两个函数多进程的执行可以通过进程池来执行，这样执行看起来更简单。

```python
func_list = [pabing, mongod]
pool = multiprocessing.Pool()
    for x in func_list:
        pool.apply_async(x)
        print type(x)
    pool.close()
    pool.join()
```

其中`Pool()`中间没传值就表示系统自动分配，也可以指定最大进程数。这样写起来看着就比较简洁，但是还是需要手工指定函数名，如果函数一多，也会出项上面那样的问题，写起来非常累，我需要的是动态执行，也就是程序自己取函数名自己执行。我想到的方法，就是把所有函数包装到一个类中。

### 一个简单的demo
```python
import multiprocessing
import time


class a(object):
	def aaa(self):
		print 1 + 1, time.time()

	def bbb(self):
		print 2 + 2, time.time()


if __name__ == '__main__':
	b = a()
	func_list = []
	for x in dir(b):
		if x.startswith("__"):
			pass
		else:
			func_list.append(x)

	pool = multiprocessing.Pool()
	for x in func_list:
		pool.apply_async(eval("b." + x + "()"))
	pool.close()
	pool.join()
```
这样的执行结果是：

```
SvenWeng@wengyanbin:~/Desktop|⇒  python test.py
2 1470492989.2
4 1470492989.2
```

通过dir函数来获取类中的可执行函数，然后去掉“__”开头的系统的函数，就是我们自己写的函数了，dir函数返回的是str类型的数组，那么我们就只能用`eval`这个方法来直接执行，结果令人满意，这样就完成了动态的执行类中所有的方法，以后如果有新的服务，就只需要在类中增加方法即可。
